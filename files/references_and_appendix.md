## Appendix Table A4: SE Ratio Verification (Substitution vs Bootstrap)

| Dataset | $n$ | $L$ | Substitution asymp SE | Bootstrap SE | Ratio | Implication |
|---------|-----|-----|----------------------|--------------|-------|-------------|
| UCI Portuguese | 649 | 2 | 0.273 | 0.507 | 1.86 | Moderate underestimation |
| xAPI | 480 | 12 | 0.018 | 0.068 | 3.78 | Severe (cluster-aware needed) |
| Law School | 21,791 | 1 | 0.0000034 | 0.0081 | — | Pathological (degenerate) |
| OULAD | 25,820 | 22 | 0.0023 | 0.0081 | 3.52 | Severe (cluster-aware needed) |

Bootstrap inference is the gold standard for honest variance characterization. On clustered datasets (xAPI, OULAD), asymptotic SE from the substitution estimator underestimates bootstrap SE by approximately 3.5×–4×. The Law School case ($L = 1$, large $n$) exhibits a qualitatively different pathological failure: the asymptotic SE collapses to a near-zero value several orders of magnitude smaller than bootstrap SE, reflecting a degenerate behavior of the score-based variance formula rather than a systematic underestimation pattern. We exclude this case from the ratio column to avoid an unrepresentative figure. The general lesson is that asymptotic SE from substitution-based estimators should not be trusted without bootstrap verification, particularly in clustered or large-$n$ IID settings.

## B.2 Configuration

Default hyperparameters used throughout experiments:

```python
# Cross-fitting
n_folds = 3
n_cluster_folds = min(3, L)  # for hierarchical datasets

# Stability

clip_density_ratio = 5.0  # density ratios clipped to [0.2, 5.0]
trim_percentile = 99  # MAD threshold = 10 MAD around median (~ 10 SD)

# Monte Carlo
n_mc_samples = 50  # for marginalized outcomes

# Bootstrap
n_bootstrap = 200  # for paper-quality inference
bootstrap_method = 'cluster'  # for hierarchical datasets

# Verification
N_LARGE = 10000  # for verify_eif_estimator
```
